# 💰 EyeOfWages — учёт зарплаты

[![Версия](https://img.shields.io/badge/Version-1.5.0-blue.svg)](CHANGELOG.md)
[![Лицензия](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**EyeOfWages** — Android-приложение для учёта ежемесячной зарплаты, анализа доходов и расчёта отпускных. Приложение помогает хранить историю расчётов, отслеживать изменения дохода и контролировать основные показатели заработной платы.

Создано на **Kotlin** с использованием **Jetpack Compose**.

---

## ✨ Основные возможности

- **Ежемесячный учёт:** ведение записей о зарплате, авансе, налогах и норме рабочего времени.
- **Расчёт отпускных:** автоматический расчёт среднего дневного заработка (СДЗ) на основе данных за предшествующие 12 месяцев.
- **Учёт исключаемых периодов и сумм:** исключение больничных и предыдущих отпускных из базы расчёта СДЗ в соответствии с реализованной логикой приложения.
- **История зарплаты:** просмотр изменений дохода за выбранный период с помощью интерактивного графика.
- **Статистика:** анализ средней, минимальной и максимальной зарплаты.
- **Сравнение доходов:** сравнение зарплаты с предыдущим месяцем.
- **Поиск и сортировка:** быстрый поиск записей и изменение порядка отображения месяцев.
- **Удаление свайпом:** удаление записей с подтверждением действия.
- **Обновление данных:** поддержка обновления данных жестом Pull-to-Refresh.
- **Информационный экран:** просмотр истории версий и планов развития приложения.

## 💻 Установка и запуск

### Требования

- Android Studio с поддержкой используемой в проекте версии Android Gradle Plugin.
- Android SDK, соответствующий настройкам проекта.
- JDK, совместимый с используемой версией Gradle.

Точные версии инструментов определяются конфигурацией Gradle проекта.

### Инструкция

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/EgorPoprotskiy/EyeOfWages.git
   ```

2. **Откройте проект:** запустите Android Studio и откройте клонированную папку как Gradle-проект.

3. **Дождитесь синхронизации Gradle:** Android Studio загрузит необходимые зависимости.

4. **Соберите и запустите приложение:** выберите эмулятор или подключённое Android-устройство и запустите конфигурацию приложения.
